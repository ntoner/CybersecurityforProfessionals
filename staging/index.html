04 — SECURITY AUDIT

TLS & Certificate Security Audit

I performed a TLS security assessment of several intentionally vulnerable test environments using SSL Labs and OpenSSL.

tls-v1-1.badssl.com

SSL Labs Grade: B

TLS 1.1 was supported alongside TLS 1.2. TLS 1.1 is deprecated and should be disabled.

Severity: Medium

Recommendation: Require TLS 1.2 or TLS 1.3.

dh480.badssl.com

SSL Labs Grade: F

Testing identified an insecure 480-bit Diffie-Hellman parameter configuration.

Severity: High

Recommendation: Replace weak DH parameters with strong parameters of at least 2048 bits.

incomplete-chain.badssl.com

SSL Labs Grade: B

OpenSSL reported an incomplete certificate chain because the required intermediate certificate was not provided.

Severity: Medium

Recommendation: Configure the server to provide the complete certificate chain.

Audit Summary

The audit demonstrated that secure TLS requires more than simply having HTTPS enabled. Protocol versions, cryptographic parameters, and certificate chains all affect the security of encrypted communications. The most serious finding was the weak Diffie-Hellman configuration, while the other findings involved deprecated protocol support and certificate-chain configuration.
