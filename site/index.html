FINDING 01

tls-v1-1.badssl.com

B
Severity: Medium Issue: Deprecated TLS 1.1

Finding

TLS 1.1 is supported alongside TLS 1.2. TLS 1.1 is deprecated and should no longer be used.

Risk

Supporting an outdated protocol increases the attack surface and may expose users to weaknesses associated with legacy TLS implementations.

Remediation

Disable TLS 1.1 and require TLS 1.2 or TLS 1.3 for client connections.

FINDING 02

dh480.badssl.com

F
Severity: High Issue: Weak Diffie-Hellman Parameters

Finding

The server uses an insecure 480-bit Diffie-Hellman parameter configuration.

Risk

Weak Diffie-Hellman parameters reduce the security of the cryptographic key exchange.

Remediation

Replace the weak parameters with strong DH parameters of at least 2048 bits and use a modern TLS configuration.

FINDING 03

incomplete-chain.badssl.com

B
Severity: Medium Issue: Incomplete Certificate Chain

Finding

The server does not provide the complete certificate chain. OpenSSL reported an inability to verify the certificate issuer.

Risk

Clients may fail certificate validation or display security warnings when connecting to the server.

Remediation

Configure the server to provide the complete certificate chain, including the required intermediate certificates.
